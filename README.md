## Features/Additions:
| Features                                                                                                |
|:--------------------------------------------------------------------------------------------------------|
| Included Crowded Support, meaning you can play with 15+ players on Modded Regions.                      |
| Adds support for **ehT dlekS**, so you can play it in Project: Lotus.                                   | 
| "Functional" support for The Fungle (You can play the CTF & ETF Gamemodes, as well as use Random Spawn) | 
| "Functional" support for Submerged (Random Spawn support & CTF Support)                                 | 
| 9 new modifiers, 8 new roles, and more on the way!                                                      | 
| Command Suggestions: Autocomplete commands by pressing tab while typing one.                            | 
| Various cut/removed features (re)implemented                                                            |
| Various UI Improvements.                                                                                | 
| Shows notification messages in meeting displaying the time left.                                        | 
| Show the result of the previous meeting above the Meeting Table.                                        |
| Private chats for Impostors, Romantics & Jailor/Jailed People.                                          |
| Support for changing the scale of the GUI.                                                              |
| Support for zooming the camera out when dead or when in lobby.                                          |
| A simple in-game anticheat for blocking malicious hackers in lobby.                                     | 
| Option to automatically recreate your lobby upon disconnecting, mainly for auto-hosters.                |
| Various new commands for moderation, fun, and miscellaenous things.                                     |
| Various custom buttons for roles (which replace the vanilla buttons).                                   |
| **Even more for you to discover! (i forgot the rest)**

## Commands

:::note
> Some commands are required to use the /cmd prefix, while others can use either / or /cmd.
:::

|  Prefix  | Command Name  |      Flags       | Description                                                                                               |
|:--------:|:--------------|:----------------:|-----------------------------------------------------------------------------------------------------------| 
|   /cmd   | archangelchat |  In-Game, Host   | Talk to your Archangel partner as an Archangel                                                            |
| / & /cmd | endmeeting    | In-Meeting, Host | Ends the currently active meeting.                                                                        |
|   /cmd   | impostorchat  |   In-Game Only   | Send a message to your impostor partners.                                                                 |
|   /cmd   | jailorchat    |   In-Game Only   | If Jailor or Jailed, talk to the Jailed/Jailor.                                                           |
|   /cmd   | romanticschat |   In-Game Only   | Talk to your romantic partner as a Romantic (or romanced player)                                          |
| / & /cmd | kill          |  Moderator Only  | Kill/Execute a player                                                                                     |
| / & /cmd | rtp           |   In-Game Only   | Teleport to a random room on the map (when dead.)                                                         |
| / & /cmd | roulette      |   In-Game Only   | Play a game of Russian Roulette, if you lose then you will be kicked. (Host can disable this in settings  | 
|   /cmd   | vote          |   In-Game Only   | Vote a player in the current meeting (meant for when using Crowded.)                                      |
|   /cmd   | will          |  In-Game Only    | Write a will, which will be displayed in meeting upon your death. (Host can disable this in settings)     |
